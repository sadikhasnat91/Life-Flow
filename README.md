# 🌟 LifeFlow – Digital Life Organizer App

**LifeFlow** is a modern, feature-rich Flutter application designed to help users organize their daily life efficiently. It combines task management, goal tracking, habit building, and smart reminders into one powerful productivity system.

This app is built as a final year project with a focus on **real-life usability, clean architecture, and premium UI/UX design**.

---

## 🚀 Features

### 📊 Dashboard

* Overview of daily tasks, goals, and habits
* Progress tracking with visual indicators
* Motivational quotes for daily inspiration

### ✅ Task Manager

* Create, edit, and delete tasks
* Set deadlines with date & time
* Priority levels (Low, Medium, High)
* Mark tasks as completed
* Search and filter functionality

### 🎯 Goal Management (Smart System)

* Set long-term and short-term goals
* Add deadline (date & time)
* 🔔 Smart Notifications:

  * Reminder before deadline (1 day / 1 hour / 10 min)
  * ⏰ Alarm-style alert at exact deadline
* Track goal completion progress

### 🔥 Habit Tracker

* Build daily habits (gym, study, reading, etc.)
* Streak tracking system
* Calendar-based habit visualization
* Progress charts

### 📝 Notes

* Create and manage personal notes
* Clean and minimal card-based UI

### 🔔 Reminder System

* Local notifications for tasks, goals, and habits
* Repeating reminders (daily/weekly)

### 👤 Profile & Settings

* User profile with stats (tasks completed, streaks, goals achieved)
* Dark/Light mode toggle
* Notification settings

├── services/
├── views/
├── widgets/

* Reusable components
